# Private Startup

A private, purpose-built B2B software product for companies in and around Birmingham, UK.

This repository was reset from a previous project. The current phase is **research and
product definition**: choosing a target industry, mapping its day-to-day operational
problems, and defining the single highest-value software product to build.

## Repository layout

- `docs/` — research briefs, industry analysis, and the product decision
- `.claude/skills/` — Claude Code skills installed to support building this product
